## Self-review findings and concerns

- **I3 uses a new alert kind `web_tls_expiring`, not `tls_expiring`.** The store allows
  one open alert per `(kind, server_id)`. Sharing the kind would hide the web alert
  whenever the panel host's own MySQL certificate also expires soon. The spec's wording
  ("tls_expiring … MySQL/web") is met in substance, and the new kind is listed in
  `AllKinds`, so it has its own notification toggle. A reviewer may prefer server_id 0;
  `alerts.server_id` has a foreign key to `servers`, so that would need a schema change.
- **I8 needs a migration (0007), not an edit of 0006.** Databases already at version 6 on
  this branch keep working. A certificate installed before 0007 has empty hosts and is
  treated as "unknown", so it never refuses. Only certificates installed or renewed
  after the fix are checked.
- **SEC-56 guard.**
  - It depends on `performance_schema` with the MDL instrument (on by default in 8.0).
    Without it nothing is seen, and errors go to debug only.
  - The 1-minute bound is a judgment call. A dump whose FTWRL stays GRANTED that long,
    because FLUSH waits for a long query, is killed and its job fails. That trades a
    failed copy for the master's writes, as intended.
  - Every guard pass opens a fresh admin pool (every 15 s), which is cheap but not reused
    the way Snapshot reuses its own.
- **SEC-56 `MAX_USER_CONNECTIONS 2`.** mysqldump uses one session. Each attempt creates a
  new random account, so retries do not share the limit.
- **I5.** The revert re-CHANGEs with `SSL: true` even if the topology originally ran
  without TLS. The master was just given a certificate in step 0, so TLS is available.
- **I1.** A regeneration triggered by an operator name also constrains to the interface
  subnets present at that moment, docker bridges included. It is a new CA, so "at
  creation" holds. SEC-55 butir 1 (/32 constraints, excluding virtual interfaces) remains
  "before release", as the audit schedules it.
- **SEC-55.** The public-suffix list is small and built in. A name under an unlisted
