Pasang ulang agent di {{.Server.Name}}?

Gunakan ini bila server dipasang ulang atau isi /etc/dbpanel hilang. Panel membuat token pemasangan baru dan menampilkan perintahnya. Begitu agent baru berhasil dipasangkan, sertifikat agent lama tidak berlaku lagi dan agent lama tidak bisa terhubung. Sampai saat itu agent lama tetap bekerja.

 {{end}}

Hapus server {{.Server.Name}}?

Server akan dihapus dari panel, koneksi agent-nya langsung diputus, dan sertifikatnya tidak diterima lagi. Service dbpanel-agent di server itu tetap terpasang dan terus mencoba terhubung sampai dimatikan (sudo systemctl disable --now dbpanel-agent). Data di server itu sendiri tidak disentuh. Untuk memakainya lagi, tambahkan ulang server ini dan jalankan perintah pemasangan yang baru.
