    Unduh sertifikat

    Browser menampilkan peringatan? Unduh berkas ini, klik dua kali, pilih Pasang, lalu buka panel lagi.

    Unduh sertifikat keamanan panel

    Cukup sekali untuk tiap komputer atau ponsel. Setelah terpasang, browser membuka panel tanpa peringatan dan sambungannya terenkripsi. Sertifikat ini hanya berlaku untuk alamat panel ini: nama panel beserta semua subnamanya, dan alamat IP di jaringan panel.

  3. 3

    Pasang menurut sistem

    Windows, macOS, Firefox, Android, iPhone dan iPad: langkahnya di bawah ini.

Windows (Chrome, Edge)

  1. Cocokkan sidik jari dulu: buka Command Prompt di folder unduhan, jalankan certutil -dump dbpanel-panel.crt, lalu bandingkan baris Cert Hash(sha256) dengan sidik jari di atas (abaikan spasi, titik dua dan huruf besar/kecil).
  2. Klik dua kali berkas dbpanel-panel.crt yang sudah diunduh, lalu klik Install Certificate...
  3. Pilih Local Machine, klik Next, lalu Yes bila Windows meminta izin.
  4. Pilih Place all certificates in the following store, klik Browse..., pilih Trusted Root Certification Authorities, lalu OK dan Next.
  5. Klik Finish, lalu Yes pada peringatan keamanan.
  6. Tutup semua jendela browser, lalu buka panel lagi.

macOS (Safari, Chrome)

  1. Cocokkan sidik jari dulu: pilih berkas dbpanel-panel.crt di Finder dan tekan spasi (Quick Look), buka Details, lalu bandingkan SHA-256 di bagian Fingerprints dengan sidik jari di atas.
  2. Klik dua kali berkas dbpanel-panel.crt. Pada pertanyaan Keychain pilih System, lalu Add, dan masukkan kata sandi Mac.
  3. Di Keychain Access buka System, klik dua kali dbpanel-web-ca.
  4. Buka bagian Trust, ubah When using this certificate menjadi Always Trust.
  5. Tutup jendelanya dan masukkan kata sandi Mac, lalu buka panel lagi.

Firefox

Firefox memakai daftarnya sendiri, juga di Windows dan macOS.

  1. Buka Settings, pilih Privacy & Security.
  2. Di bagian Certificates klik View Certificates..., buka tab Authorities, klik Import...
  3. Pilih berkas dbpanel-panel.crt, klik View, lalu bandingkan SHA-256 di bagian Fingerprints dengan sidik jari di atas. Bila sama, centang Trust this CA to identify websites, lalu OK.
  4. Buka panel lagi.

Android

  1. Unduh berkas dengan tombol di atas.
  2. Buka Settings → Security → Encryption & credentials → Install a certificate.
  3. Pilih CA certificate, ketuk Install anyway, lalu pilih berkas dbpanel-panel.crt.
  4. Cocokkan sidik jari: buka Trusted credentials → User, ketuk dbpanel-web-ca, lalu bandingkan sidik jari SHA-256 dengan yang di atas. Bila berbeda, ketuk Remove.
  5. Buka panel lagi. Nama menu bisa sedikit berbeda menurut merek ponsel; cari "certificate" di Settings.

iPhone dan iPad

  1. Buka halaman ini di Safari, ketuk tombol unduh, lalu Allow.
  2. Buka Settings, ketuk Profile Downloaded, ketuk More Details lalu nama sertifikat, dan bandingkan SHA-256 di bagian Fingerprints dengan sidik jari di atas. Bila sama, ketuk Install dan masukkan kode sandi.
  3. Buka Settings → General → About → Certificate Trust Settings, aktifkan dbpanel-web-ca, lalu Continue.
  4. Buka panel lagi.

Banyak komputer sekaligus

Admin domain Windows bisa menyebarkan berkas ini ke semua komputer lewat Group Policy (Computer Configuration → Policies → Windows Settings → Security Settings → Public Key Policies → Trusted Root Certification Authorities). Ambil berkasnya langsung dari server panel (/etc/dbpanel/panel/web-ca.crt, lewat SSH atau flashdisk) dan cocokkan sidik jarinya, jangan dari unduhan browser.
