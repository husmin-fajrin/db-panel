Cara menyalin data

Biasanya panel menyalin data dengan CLONE bila bisa (lebih cepat). Centang ini untuk selalu memakai dump.

Saat salinan dimulai, master dikunci sesaat (semua penulisan berhenti sebentar) agar datanya konsisten. Bila di master sedang berjalan kueri panjang (misalnya laporan bulanan), kunci itu menunggu kueri tersebut dan penulisan aplikasi ikut tertahan. Buat replika di jam sepi.
Server tujuan harus server replika khusus: seluruh MySQL di server itu dikunci hanya-baca (read_only + super_read_only) dan semua database lamanya dibuang. Aplikasi lain di server itu tidak bisa menulis.
